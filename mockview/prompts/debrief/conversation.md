Write the section "## 4. Talking about yourself and your thinking".

Cover, each as its own subsection:
1. **"Tell me about yourself"**: critique (structure, specificity, numbers, relevance to Bloomberg, length) and a model answer written in
   the candidate's voice from their resume (60–90 seconds spoken).
2. **Resume follow-ups**: for every resume question asked: the question, a summary of what they answered, what the interviewer was
   really testing, what was missing, and a model answer built from the resume. Then list 3–5 more questions this interviewer would
   likely ask about this resume, with short model answers.
3. **The hard problem**: critique using a clear structure (context, problem, investigation, root cause, fix, verification, result,
   lesson) and a model answer from their resume.
4. **Data-structure and complexity questions**: every question that was asked AND every question in interviewer-notes.md for this
   exercise: the question, their answer (if any), and a model answer covering complexity, alternatives and trade-offs.
5. **Feature requests**: every feature request in interviewer-notes.md: how a strong candidate would approach it (clarifying questions,
   design, data structures, edge cases, tests), and how the candidate's answer compared if it came up.
6. **Your questions for the interviewer**: critique of what they asked and 5 better questions for a Bloomberg engineer.
